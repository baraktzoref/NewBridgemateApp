# הרצת פיילוט על מחשב Windows

מדריך זה מסביר איך להריץ ערב ברידג' אמיתי (פיילוט) על מחשב Windows אחד,
עם הטלפונים של זוגות צפון-דרום מתחברים אליו מהשולחנות דרך WiFi.

אין צורך בהתקנה "אמיתית" (installer.exe) — הכול רץ ישירות מהקוד דרך
כמה קבצי `.bat` שמריצים את Node.js בשבילכם. זה דורש שהמחשב והטלפונים
יהיו **על אותה רשת WiFi** (למשל רשת ה-WiFi של המועדון).

## התקנה בקובץ אחד (setup.exe) — מומלץ

במקום הסקריפטים שלמטה, אפשר להשתמש במתקין אחד שכולל Node.js נייד, כלל חומת אש לפורט 8080 וקיצורי דרך
("Start Bridge Server", "Create New Event", "Director Screen"):

1. ב-GitHub: Actions > "Build Windows installer" > Run workflow (או לדחוף תג `v1.0.0`, ואז הקובץ מצורף ל-Release).
2. מורידים את `NewBridgemate-Setup-*.exe` מה-Artifacts, מעבירים למחשב ה-Windows ומריצים.
3. מפעילים "Start Bridge Server", ואז "Create New Event". מסד הנתונים נשמר ב-`C:\ProgramData\NewBridgemate`, וגיליון ההדפסה ב-`Documents\NewBridgemate`.

המתקין נבנה ב-CI ולא נבדק עדיין על מחשב Windows אמיתי — ההרצה הראשונה צריכה להיות בדיקה.

## התקנה ידנית מהקוד (ללא מתקין)

## מה צריך מראש

1. מחשב Windows, מחובר לרשת WiFi שגם הטלפונים יתחברו אליה.
2. Node.js גרסה 22.5 ומעלה — אם לא מותקן, `windows\install.bat` יגיד
   לכם זאת ויכוון אתכם להורדה מ-https://nodejs.org
3. עותק של תיקיית הפרויקט הזו (`newbridgemateapp`) על המחשב.

## שלבים

### 1. התקנה (פעם אחת בלבד)

לחיצה כפולה על:

```
windows\install.bat
```

זה יבדוק ש-Node.js מותקן ויתקין את כל מה שהפרויקט צריך. ייתכן שיקח
כמה דקות בפעם הראשונה. בסוף יופיע "ההתקנה הסתיימה בהצלחה!".

### 2. הפעלת השרת

לחיצה כפולה על:

```
windows\start-server.bat
```

חלון ה-cmd שנפתח:
- מדפיס את כתובות ה-IP של המחשב (למשל `192.168.1.23`) — **זו הכתובת
  שהטלפונים צריכים**, לא `localhost`.
- ייתכן שתופיע התראה של **Windows Defender Firewall** — לוחצים
  **"אפשר גישה" (Allow access)**, אחרת הטלפונים לא יוכלו להתחבר.
- יש להשאיר את החלון הזה **פתוח במשך כל הערב**. סגירתו מפסיקה את
  השרת (ואת המשחק...). להפסקה מכוונת: Ctrl+C.

### 3. יצירת הערב (אירוע)

**בחלון cmd חדש ונפרד** (לא זה של השרת!), לחיצה כפולה על:

```
windows\create-event.bat
```

יתבקשו: שם הערב, מספר זוגות, ומספר לוחות לסיבוב. בסיום ייפתח
בדפדפן **גיליון הדפסה** עם:
- כתובת ייחודית לכל שולחן (למשל `http://192.168.1.23:8080/t/<token>`)
- קוד האירוע (eventCode) שיוזן בטלפונים
- **ה-PIN של המנהל** — מופיע פעם אחת בלבד! יש לשמור אותו (לצלם/לכתוב),
  הוא לא יוצג שוב ולא ניתן לשחזור.

לוחצים Ctrl+P בעמוד שנפתח כדי להדפיס את גיליון השולחנות, או משאירים
אותו פתוח על המסך.

### 4. חיבור הטלפונים

בכל שולחן, זוג צפון-דרום פותח בדפדפן הטלפון שלו את הכתובת שמופיעה
בכרטיס של השולחן שלו (מהגיליון שהודפס).

**הערה חשובה (מגבלה ידועה):** הכתובות האלה כוללות קוד אקראי ארוך
(32 תווים) ולא נוחות להקלדה ידנית. הדרך הטובה ביותר להעביר אותן
לטלפון של השולחן היא **שיתוף ישיר מהטלפון של המנהל** (AirDrop, שיתוף
קישור ב-WhatsApp/הודעה, וכו'), ולא הקלדה אות-אחר-אות. הטבעת קודי QR
על גיליון ההדפסה מתוכננת כשיפור עתידי ואינה קיימת עדיין בגרסה הזו.

### 5. מסך המנהל

בדפדפן (גם במחשב וגם בטלפון של המנהל), נכנסים לכתובת:

```
http://<כתובת-ה-IP-של-המחשב>:8080/director
```

ומתחברים עם `eventId` וה-PIN שהתקבלו בשלב 3. במסך המנהל ניתן לראות
את מצב כל השולחנות בזמן אמת, לקדם סבבים, לנעול/לשחרר שולחן, לנתק
מכשיר, ולערוך/לבצע Override לתוצאה.

## בעיות נפוצות

- **"לא ניתן להתחבר לשרת"** בעת יצירת האירוע — ודאו ש-
  `windows\start-server.bat` עדיין רץ בחלון אחר.
- **הטלפון לא מצליח להיכנס לכתובת** — ודאו שהטלפון מחובר לאותה
  רשת WiFi כמו המחשב (לא לרשת סלולרית!), ושחומת האש אישרה גישה.
- **השרת ייסגר אם המחשב ייכנס למצב שינה (Sleep)** — מומלץ לכבות
  מצב שינה אוטומטי במחשב למשך הערב (הגדרות Windows > מצב צפייה ושינה).

## מה עוד מתוכנן

- קודי QR על גיליון השולחנות (כדי לא להעביר/להקליד כתובות ארוכות).
- דרך לשחזור/איפוס PIN למנהל במקרה שנשכח.
